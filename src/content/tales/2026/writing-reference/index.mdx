## 路線圖

預設是爬升剖面。一條俯視的曲線只說明「繞了一圈」，讀者想知道的是那裡有多陡。

<Route of="whistler-utmb-100k-2026" />

**把圖跟段落綁在一起**，才是它比裝飾多出來的那部分。下面這段在講 40 到 55 公里
那段連續爬升，圖就只亮那一段：

<Route of="whistler-utmb-100k-2026" from={40} to={55} caption="Singing Pass 到 Musical Bumps" />

標一個點：

<Route of="canadian-death-race-2026" at={70} label="Hamel 山頂" />

## 排版

一般 Markdown 全都照常。中文行高 1.9、行長 34 個全形字，刻意不用
`@tailwindcss/typography`——它的 1.75 和 65ch 是拉丁習慣，套到中文像跑馬拉松。

### 三級標題

清單：

- 第一項
- 第二項，句子長一點看看換行之後的縮排對不對，中文的斷行規則跟英文不一樣
- 第三項

有序清單：

1. 先讀 schema
2. 再讀畫面
3. 最後才猜

引用：

> 十趟，單數趟徒手、雙數趟帶杖。
> 差異不顯著，但心率低了六下。

程式碼（Shiki，墨色主題）：

```bash
pnpm new "新文章標題" --slug new-post --date 2026-09
```
